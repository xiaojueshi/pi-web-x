# pi-web-x v0.9.1 发布说明

> 发布前按 [`../release.md`](../release.md) 核对制品、校验和与跨平台验收。

## 概要

v0.9.1 提升自更新后的服务连续性：更新二进制后，会自动恢复已注册的用户级系统服务；旧安装根迁移到 `~/.pi-web-x` 时，服务定义中的绝对路径也会同步修复。Pi SDK 全家桶同步升级至 `0.84.4`。

## 新增与改进

- **自动恢复服务**：`pi-web-x update` 成功替换二进制后，自动检测已注册服务并重启。systemd 会验证服务为 `active`；launchd 会验证 LaunchAgent 已加载；Windows 计划任务会在二进制成功替换后重新运行。
- **安装根迁移联动**：从 `~/pi-web-x` 迁移到 `~/.pi-web-x` 时，systemd 与 launchd 的二进制路径会自动更新。systemd 的旧配置快照复制到 `~/.pi-web-x/env`，保留端口、监听地址与 Basic Auth 密码。
- **失败可恢复**：二进制更新成功但服务恢复失败时，命令返回非零并报告服务管理器错误；新二进制与旧版备份均会保留，无需重新下载。
- **Pi 基线**：`@earendil-works/pi-agent-core`、`pi-ai`、`pi-coding-agent`、`pi-tui` 均升级到 `0.84.4`。该版本未声明相对于 `0.84.3` 的 Breaking Changes。

完整变更见 [`../../CHANGELOG.md`](../../CHANGELOG.md)。

## 兼容与安全

- 产品命名空间保持断裂：`pi-web-x` 不读取、迁移或兼容旧 `pi-web:*` 浏览器标识；Pi 通用数据仍位于 `~/.pi/agent`。
- 默认仅监听 loopback。LAN 或反向代理部署必须使用 HTTPS，并使用浏览器访问认证或 `PI_WEB_X_PASSWORD`，或置于可信 VPN 后。
- Host/Origin 校验及 Host Runtime Environment 与 Project Command Environment 的隔离保持不变。
- Windows 正在运行的 `.exe` 受操作系统文件锁限制；只有二进制替换成功后，计划任务才会自动重启。

## 构建与制品

- 构建环境：Bun `1.4.0`。
- 制品目标：darwin x64/arm64、linux glibc x64/arm64、linux musl x64/arm64、windows x64/arm64。
- Draft Release 必须包含八个 `pi-web-x-*` 二进制、`pi-web-x-assets-0.9.1.tar.gz` 及 `SHA256SUMS`。
- GitHub Actions 在推送 `v0.9.1` 后自动创建 Draft Release；确认制品与校验和后发布。
