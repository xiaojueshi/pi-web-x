# Built-in subagent trust, observation, and lifecycle boundary

Pi Web X keeps its Built-in Inline Subagent manually exclusive with External Subagent Extensions, as recorded in ADR 0003. It provides an always-available Subagents settings area: built-in and workspace profiles are read-only; global and trusted-project profiles support full management, retain source-precedence visibility, and require confirmations for sensitive capabilities and deletion. Repository-scoped profiles are unavailable until the project is trusted: first selecting an untrusted project's session prompts once per browser visit, while a persistent restricted-functionality notice and trust action remain after dismissal. The Agents observation view is limited to the current parent session, shows running and total counts, and makes child sessions strictly read-only in both UI and API. Stopping a parent Agent aborts every active built-in child without re-notifying or restarting that parent; normal background completion continues to follow up to the parent, while foreground delegation waits and continues in the same parent turn.

## Considered Options

We rejected automatic external-plugin precedence because plugin installation or upgrades must not silently change delegation behavior. We rejected loading repository profiles before project trust because their prompts and optional extensions are repository-controlled input. We rejected frontend-only child-session read-only behavior because direct API calls would bypass it. We rejected repeated trust modals because a persistent restriction notice preserves informed choice without blocking normal inspection.
