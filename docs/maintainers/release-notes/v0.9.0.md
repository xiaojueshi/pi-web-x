# pi-web-x v0.9.0 发布说明

> 状态：**Released**。本文是已发布版本的冻结归档；发布流程见 [`../release.md`](../release.md)。

## 概要

v0.9.0 新增浏览器访问认证和移动 PWA Companion，并将 macOS/Linux 的默认安装根迁移到 `~/.pi-web-x`。它仍是运行在本机或受保护服务端上的 Bun 原生 Web 界面；PWA 不是离线 Agent 或原生应用替代品。

## 新增与改进

- **浏览器访问认证**：首次启动在服务器日志中输出一次性设置令牌；完成初始化后使用密码和 HttpOnly 会话 Cookie 登录。可在“设置 → 安全”修改密码（使所有设备重新登录）或退出当前设备。
- **PWA Companion**：支持由用户确认后应用 Service Worker 更新、由用户主动授权任务完成通知，以及根据 HTTPS、安全上下文和认证状态说明功能限制。未发送草稿仅保存在当前浏览会话；离线时不会执行 Agent、缓存会话历史或排队写入。
- **安装目录**：macOS/Linux 默认安装到 `~/.pi-web-x`，旧的 `~/pi-web-x` 自动迁移；`~/.local/bin/pi-web-x` 仍是命令入口。Windows 默认安装到 `%USERPROFILE%\pi-web-x` 并注册用户级 PATH。
- **设置界面**：安全页复用设置“常规”页面的共享布局；设置样式通过全局 CSS 构建管道发布，避免独立样式资源遗漏。

完整变更见 [`../../../CHANGELOG.md`](../../../CHANGELOG.md)。

## 兼容与安全

- 产品命名空间保持断裂：`pi-web-x` 不读取、迁移或兼容旧 `pi-web:*` 浏览器标识；Pi 通用数据仍位于 `~/.pi/agent`。
- 默认仅监听 loopback。LAN 或反向代理部署必须使用 HTTPS，并使用浏览器访问认证或 `PI_WEB_X_PASSWORD`，或置于可信 VPN 后。
- Host/Origin 校验及 Host Runtime Environment 与 Project Command Environment 的隔离保持不变。
- 本版本没有新增、删除或替代运行时依赖；详见 [`../runtime-substitution-matrix.md`](../runtime-substitution-matrix.md)。

## 构建与制品

- 构建环境：Bun `1.4.0`。
- 制品目标：darwin x64/arm64、linux glibc x64/arm64、linux musl x64/arm64、windows x64/arm64。
- Draft Release 必须包含八个 `pi-web-x-*` 二进制、`pi-web-x-assets-0.9.0.tar.gz` 及 `SHA256SUMS`。
- GitHub Actions 在推送 `v0.9.0` 后自动创建 Draft Release；确认制品与校验和后再手动发布。
