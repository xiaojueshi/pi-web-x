# pi-web-x v0.12.0 发布说明

> 状态：**Released**（2026-09-21 发布）。本文是已发布版本的冻结归档；发布流程见 [`../release.md`](../release.md)。

## 概要

v0.12.0 是一个次版本发布，包含三项新增能力与六项修复，主要围绕四条主线：

1. **文件预览与删除操作更安全**：大文本文件改为按需分页预览；删除会话新增只读影响预览、确认 token 与递归删除的事务化保护。
2. **会话保持更可靠**：新增当前聊天会话的短期 Selected Session Lease，浏览器关闭/休眠后不会误清仍需保活的会话。
3. **流式输出与分支不再丢失**：重新打开运行中的会话不再清空已收到的流式输出，SSE 重连后重放 shell 工具最近输出；第一条用户消息现在也可 Fork 与"从这里编辑"。
4. **`ask_user` 升级为强制用户输入协议**：模型需要用户回答时必须调用工具，后台/失焦时通过浏览器通知提醒。

上游基线与 v0.11.2 一致（pi SDK `0.85.1`），无依赖变更。

## 新增与改进

### 大文本文件预览按需分页（用户可感知：大文件打开快、内存占用低）

- **改动前**：文本文件预览一次性加载整个文件，大文件打开慢、渲染卡顿；文件在预览期间被外部修改时，新旧内容可能混合展示。
- **改动后**：不超过 10 MiB 的文本文件以 256 KiB、UTF-8 安全的分块按需加载，文件面板提供"加载更多"按钮逐块追加；预览加载期间文件发生变化时，保留当前快照并要求用户手动刷新，不再混合两个版本的内容；无效 UTF-8 内容明确提示并提供原文件下载。
- **入口**：文件面板 / 文件查看器（`components/FileViewer.tsx`、`app/api/files/[...path]/route.ts`）。

### 当前会话短期 Selected Session Lease（用户可感知：切走标签页后当前会话不被提前回收）

- **改动前**：浏览器关闭或长时间休眠后，服务端按空闲策略回收会话，用户回到页面时当前正在使用的会话可能已被 reap，需要冷启动。
- **改动后**：浏览器每 30 秒为当前聊天会话续租一次，服务端租约 90 秒过期；租约仅保活已经存在的当前 AgentSession，不会为历史会话冷启动。租约机制与 extension-owned background work 的 Extension Liveness 保持独立，互不影响。
- **入口**：当前聊天会话（`app/api/sessions/[id]/lease/route.ts`、`components/AppShell.tsx`）。

### 删除会话新增只读影响预览与确认 token（用户可感知：删除前看清影响、误删更难发生）

- **改动前**：删除会话直接执行，用户无法提前看到会连带删除多少 Built-in Inline Subagent 后代。
- **改动后**：确认前展示将递归删除的 Built-in Inline Subagent 后代数与运行数；删除确认通过一次性 token 完成，成功响应返回所有 `deletedSessionIds[]`，当前选中的已删后代也会正确退出选中状态。
- **入口**：会话删除确认对话框、`app/api/sessions/[id]/delete-preview/route.ts`。

## 修复

### 重开运行中的会话不再清空流式输出，SSE 重连后重放 shell 工具输出

- **改动前**：会话仍在运行时重新打开（或 SSE 断线重连），已收到的流式 assistant partial 会被清空；运行中 `bash` / `powershell` 工具的历史输出丢失，只能等下一次输出。
- **改动后**：重新打开时保留已收到的流式 partial；SSE 重连后重放运行中 shell 工具的最近输出，并在流式 tool card 中继续显示。
- **入口**：聊天窗口、`hooks/useAgentSession.ts`。

### 第一条用户消息可 Fork 与"从这里编辑"

- **改动前**：Fork 与"从这里编辑"分支入口对第一条用户消息不可用。
- **改动后**：第一条用户消息现在可 Fork，也可"从这里编辑"建立分支；首消息 Fork 产生的 child JSONL 会立即写入可重新打开的 session header。
- **入口**：消息操作菜单（`components/MessageView.tsx`）。

### 内置 Slash Command 不再重复提交

- **改动前**：内置 Slash Command 执行期间连续按 Enter 或点击发送，会重复提交同一命令。
- **改动后**：内置命令执行期间锁定输入控件和同步重入入口，连续 Enter 或点击不再重复提交。
- **入口**：聊天输入框（`components/ChatInput.tsx`）。

### 保存 Subagent Profile 不再破坏自定义 frontmatter

- **改动前**：通过 UI 保存 Built-in Inline Subagent Profile 时，pi-web-x 不管理的 YAML frontmatter 字段和 `ext:` tool selector 可能被丢弃。
- **改动后**：保存时原样保留这些字段；`ext:` selector 仍不被解释或赋权。若现有 frontmatter 已损坏，保存会拒绝覆盖原文件，避免坏上加坏。
- **入口**：Subagent Profile 编辑器（`app/api/subagents/profiles/route.ts`、`lib/frontmatter.ts`）。

### 删除 parent session 不再误伤 Built-in Inline Subagent

- **改动前**：删除 parent session 会将 Built-in Inline Subagent 一并改挂或删除，行为不可预期且失败时可能留下不一致的文件状态。
- **改动后**：无运行中后代时，服务端先对全部受影响 JSONL 创建操作级备份，再递归删除；普通 fork child 仍保留并改挂或去父化。任一改挂或删除失败都会恢复完整文件集；若恢复本身失败，磁盘备份保留供人工恢复。每次删除前后核验 preview 绑定的文件版本，确认 token 过期、后代树/文件变化或出现运行中后代时返回 409，不做任何文件修改。删除确认不再允许 Shift 绕过。
- **入口**：会话删除（`app/api/sessions/[id]/route.ts`，设计记录见 `docs/adr/0010-parent-session-deletion-cascade.md`）。

### `ask_user` 升级为强制用户输入协议，后台提醒接通浏览器通知

- **改动前**：模型可以在普通 assistant 文本里直接提问、列选项或留下待答决策，绕过 `ask_user` 工具；用户切走页面时收不到任何提醒；内联提问卡片在消息流中的滚动与列宽表现不佳。
- **改动后**：
  - 每轮注入规则升级为强制用户输入协议：模型需要用户回答、选择、偏好、批准或澄清时，必须先调用 `ask_user` 工具，不能在普通文本中直接提问。
  - `ask_user` 被识别为阻塞式扩展请求：页面隐藏或失焦且浏览器通知已授权时，走现有 Service Worker / 浏览器通知链提醒用户回答。
  - 内联提问卡片在 React 挂载完成后滚至消息流底部，并填满与聊天内容相同的列宽。
- **入口**：聊天窗口提问卡片（`components/ExtensionPromptCard.tsx`）、`lib/ask-user-extension.ts`、`lib/browser-notifications.ts`。

## 兼容与安全

- `/api/*` 路径、方法、状态码、JSON 字段与 SSE 事件语义保持兼容；新增 `app/api/sessions/[id]/lease` 与 `app/api/sessions/[id]/delete-preview` 两个端点。
- 产品命名空间保持断裂：`pi-web-x` / `PI_WEB_X_*` / `pi-web-x:*`，不读取或迁移旧 `pi-web:*` 浏览器标识。Pi 通用 session 消息与配置格式保持兼容。
- 默认仅监听 loopback。LAN 或反向代理部署必须显式 `-H` 并使用 HTTPS、`PI_WEB_X_PASSWORD` 或可信 VPN。
- Host/Origin 校验（`lib/request-security.ts`）以及 Host Runtime Environment 与 Project Command Environment 的隔离保持不变。
- 文件访问边界仍限于会话 cwd、项目根、已授权根与 `~/pi-cwd-*`；built-in subagents 默认关闭、设置损坏时 fail closed 的行为不变。
- 无依赖变更，`docs/maintainers/runtime-substitution-matrix.md` 无需同步更新。
- 上游基线与 v0.11.2 一致（pi SDK `0.85.1`，构建环境 Bun `1.4.0`）。
