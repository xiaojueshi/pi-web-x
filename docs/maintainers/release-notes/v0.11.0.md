# pi-web-x v0.11.0 发布说明

> 状态：**Released**。本文是已发布版本的冻结归档；发布流程见 [`../release.md`](../release.md)。

## 概要

v0.11.0 是一个功能版本：正式启用内置 Subagent 并补齐管理、信任边界与观察能力，新增批量问答、全局系统提示词、会话全文搜索与插件更新检查，同时完成上游 v0.9.0 的选择性移植与一批稳定性修复：

1. **内置 Subagent 正式可用**。此前内置 subagent 被硬编码禁用，写配置也无法开启；现在提供设置开关、profile 管理（含来源优先级与项目信任）、父会话范围内的只读观察视图，以及父 Agent 中止时的级联生命周期（详见 [ADR 0009](../../adr/0009-built-in-subagent-trust-observation-and-lifecycle.md)）。
2. **模型不再"自作主张"**。启用 Agent 工具的会话注入主动委派策略；`ask_user` 支持 2–8 个问题一次批量提问，并注入主动澄清策略，模型在歧义或高风险决策前优先询问用户。
3. **全局系统提示词可在网页端编辑**。设置面板直接读写 `~/.pi/agent/SYSTEM.md`，发现顺序与 Pi 全局资源一致（SYSTEM.md → 全局 AGENTS.md → CLAUDE.md）。
4. **找到历史会话更快**。侧边栏新增会话全文搜索（无索引字面搜索，带时间与数量预算），命中跳转并高亮定位。
5. **插件更新可见且可控**。主页与插件面板后台静默检查更新，单项/批量更新一律显式确认。
6. **制品体积明显缩小**。构建启用 minify 并移除未使用依赖，八平台二进制普遍缩小约 10MB。

## 新增与改进

### 内置 Subagent：开关、管理、信任与观察

- **开关（设置 → 通用）**：此前 `isBuiltInSubagentsEnabled()` 硬编码返回 `false`，即使手动写入 `~/.pi/agent/agents/settings.json` 也无法启用，前端无任何入口。现在设置 → 通用 提供「内置 subagent」开关，经 `GET/PUT /api/subagents/settings` 读写，默认关闭、保存即生效（无需重载会话）；设置文件损坏时 fail closed 保持关闭。非法输入返回 400。
- **Profile 管理（设置面板 Subagents 区）**：内置与 workspace 级 profile 只读展示；全局与已信任项目的 profile 可完整编辑。同名 profile 按 project → workspace → global → built-in 优先级解析，被遮蔽的来源保持可见，不会出现"重复 profile 报错"。敏感能力授权与删除操作均需显式确认。
- **项目信任边界**：仓库级（workspace/project）profile 的提示词与可选扩展属于仓库受控输入，项目被信任前不可用。首次在浏览器访问中选择未信任项目的会话时弹出一次性「项目信任提示」；拒绝后保留持久的受限功能提示与后续信任入口，不重复弹窗。
- **Agents 观察视图**：仅限当前父会话范围，显示内置子 agent 的运行中/总数、状态、消息与工具结果。子会话在 UI 与 API 两层均严格只读——直接向子会话发送消息或变更的 API 请求会被拒绝（参见 `app/api/subagents/[id]/route.ts`、`app/api/agent/[id]/route.ts`）。
- **生命周期**：停止父 Agent 会级联中止其所有活动的内置子 agent，中止历史保留供观察；前台委派在同一父回合内等待结果并继续；后台完成仍向父会话回报，不重启、不重复通知父 Agent。

### Agent 与提问行为

- **主动委派策略**：启用 Agent 工具的会话，每轮 system prompt 末尾注入委派策略——聚焦任务应主动委派给隔离上下文/专用 profile 的子 agent，独立工作用后台模式，不委派可直完成的琐碎任务，不重复委派已在进行的工作。未启用 Agent 工具时完全不修改用户的 system prompt。
- **批量 `ask_user`**：内置提问工具新增 `questions` 参数（2–8 个问题），一次调用以标签页流呈现多个独立问题；每个 tab 可自定义短标签，缺省用本地化序号。此前模型需要多次调用 `ask_user`、用户需逐个回答；现在一轮答完。单个问题（`question`/`options`/`allowMultiple`/`allowFreeform`）的原有用法与卡片行为不变。
- **主动澄清策略**：每轮注入提问策略——真正需要用户决定（歧义、实质不同的选项、不可逆/高影响假设）时先问再做，需要多项澄清时一次批量问，可安全推断的信息不打扰。

### 全局系统提示词设置

- 设置面板新增系统提示词编辑器，后端为 `GET/PUT /api/system-prompt`（`lib/system-prompt-settings.ts`）。
- 读取与 Pi 全局资源发现一致：`~/.pi/agent/SYSTEM.md` 优先；未配置时回显全局 `AGENTS.md`，再次 `CLAUDE.md`；都没有则显示空。
- 写入语义：写回当前读取的来源文件，避免把 `AGENTS.md` 内容复制进 `SYSTEM.md` 后被 SDK 重复注入；目前没有任何提示词文件时首次保存创建 `SYSTEM.md`；清空仅删除 `SYSTEM.md`，不会删除用户的全局规则文件。文件经原子写入落盘。

### 会话全文搜索

- 新增 `GET /api/sessions/search` 与侧边栏搜索面板。无索引字面搜索：单次查询 3 秒时间预算、最多扫描 500 个会话文件、返回上限 30 条，避免大会话目录下长时间阻塞。
- 结果防抖展示；点击命中跳转到对应会话并高亮定位到匹配条目。`sessionListVersion` 递增使多窗口间的会话列表保持同步。
- 适用入口：侧边栏搜索面板；API 为只读 GET，不改动任何既有路由语义。

### 插件更新检查与确认式更新

- 新增 `POST /api/plugins/check`：npm 来源用 registry 版本/范围比较，git 来源比较 HEAD 与远端 ref；识别 `PI_OFFLINE`（离线直接返回不可检查）；锁定（pinned）来源返回 unsupported；只读检查，不落盘、不自动升级。
- 自动检查时机：主页加载、项目切换与插件面板打开时后台静默执行（`lib/plugin-update-store` 全局共享状态）；检查失败不产生噪声，错误状态仅在用户手动检查时展示。
- 更新动作保持确认制：插件面板单项更新需逐项确认；批量更新先展示完整清单（含各插件当前版本 → 目标版本）再二次确认，不会静默批量升级。

### 空闲会话回收设置化

- 空闲会话回收从环境/代码默认改为设置面板管理（设置 → 通用）：可关闭或选择 5–1440 分钟超时，默认 10 分钟；持久化到 `~/.pi-web-x/settings.json`，无环境变量覆盖（[ADR 0008](../../adr/0008-idle-session-reaping-settings.md)）。
- 保活语义接入：rpc-manager 与 subagent-runtime 的后台任务按扩展后台工作口径阻止回收，避免长任务被误回收。

### 小型改进

- **Mermaid**：图渲染就绪后默认展开预览（不再需要手动点击渲染），并提供 SVG 下载。
- **阅读位置**：每个会话记住消息流阅读位置，切回会话不再跳回底部；锚点翻页后恢复位置正确。
- **视频预览**：文件面板支持视频内联预览，webm 归类为视频，按 Range 流式播放，不再触发整文件下载或下载兜底。

## 修复

- **编译二进制下 HTML 历史导出失败**：导出 API 的 fallback 硬编码 npm 包内 `dist/core/export-html` 路径并动态 import 磁盘文件；二进制部署下该目录不存在，报 `ResolveMessage: Cannot find module '~/.pi-web-x/dist/core/export-html/index.js'`，导出整体失败。现在 pi-coding-agent 的 `exportFromFile` 在编译期内嵌进二进制（`src/export-html-entry.ts`），移除对磁盘布局的依赖。用户可感知效果：单文件二进制部署（无 Node 环境）下，会话导出 HTML 恢复正常，条目与中文内容完整。入口：会话导出 API（`app/api/sessions/[id]/export`）。
- **手动上下文压缩等待超时**：压缩可能持续数分钟，HTTP 响应链路等待会超时，客户端既收不到结果也无法判断是否在进行。现在 `compact` 命令立即确认返回 `{started:true}`，完成结果与错误仍经 SDK `compaction_end` 事件通过 SSE 送达；失败在服务端日志可见（`[pi-web-x] manual compaction failed`）。入口：消息流上下文压缩操作（`/api/agent/[id]` 的 `compact` 命令）。
- **请求参数解析统一加固**：15 处 API 路由直连 `new URL(req.url)` 读取查询参数，畸形 URL 会抛出未处理异常；统一改为 `requestSearchParams()` 安全解析（失败返回空集合）。request-security 的 `getRequestOrigin` 解析失败从"继续用空值"改为 fail closed 返回 null。用户可感知效果：畸形请求不再产生 500 噪声，来源校验更严格。
- **热点正则预构建**：markdown 数学块闭标签正则由逐行 `new RegExp` 改为常量表（标签集固定）；会话 cookie 正则提升为模块常量。消除逐请求/逐行分配开销。
- **登录令牌随机源**：auth/login 的 client-input 令牌从 `Math.random` 改为 `crypto.randomUUID`（加密强度）。
- **CI 加固**：三个工作流的 checkout 显式 `persist-credentials: false`；ci/e2e 增加 `permissions: {}` 最小权限；新增 typebox 显式依赖（此前经 pi SDK 传递使用，knip 报 unlisted）。
- **测试修复**：idle-session-settings 的 Windows 路径分隔符断言（期望路径与实现同用 `node:path.join` 构造）；SettingsUi 正则断言跨规则块误匹配；会话搜索测试的 `listAllSessions` 30s globalThis 缓存跨文件污染。

## 兼容与安全

- **API 兼容**：未改动任何既有 `/api/*` 路径、方法、状态码或 JSON 字段语义；本次新增 `/api/system-prompt`（GET/PUT）、`/api/sessions/search`（GET）、`/api/plugins/check`（POST）。
- **上游基线**：选择性移植上游 pi-web v0.9.0（`0d1df12`）的插件管理增强与会话搜索；保留 `pi-web-x` 命名、Bun 单文件编译与 Host/Project 环境隔离等本地不变量，未整包跟随上游。
- **命名空间断裂不变**：`pi-web-x` 不读取、迁移或兼容旧 `pi-web:*` 浏览器标识与 localStorage；Pi 通用 session 消息和配置格式保持兼容，Pi 数据仍位于 `~/.pi/agent`。
- **默认安全面不变**：默认仅监听 loopback；Host/Origin 校验位于 `lib/request-security.ts` 且本次 Origin 解析失败改为 fail closed；LAN 部署必须显式 `-H` 并配合 `PI_WEB_X_PASSWORD`、HTTPS 或可信 VPN。Host Runtime Environment 与 Project Command Environment 隔离不变。
- **依赖变更**：pi SDK 0.85.0 → 0.85.1（保留，未替代，`docs/maintainers/runtime-substitution-matrix.md` 的 `@earendil-works/pi-*` 行语义不变）；新增 `semver`（插件版本比较）与 `typebox`（原经 pi SDK 传递使用，改为显式依赖）；移除零引用的 `@earendil-works/pi-server`。矩阵无保留/替代决策变化。

## 构建与制品

- 构建环境：Bun `1.4.0`。
- 制品目标：darwin x64/arm64、linux glibc x64/arm64、linux musl x64/arm64、windows x64/arm64，共八个 `pi-web-x-*` 单文件二进制；本次起发布构建启用 minify，单二进制约 103.7MB → 93.2MB。
- Draft Release 必须包含八个 `pi-web-x-*` 二进制、`pi-web-x-assets-0.11.0.tar.gz` 及 `SHA256SUMS`。
- GitHub Actions 在推送 `v0.11.0` tag 后自动构建并创建 Draft Release；确认八个二进制、资产包与 `SHA256SUMS` 全部上传后才可发布。

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/xiaojueshi/pi-web-x/main/install.sh | sh
```

```powershell
irm https://raw.githubusercontent.com/xiaojueshi/pi-web-x/main/install.ps1 | iex
```

安装脚本能力与 v0.10.x 一致：自动探测 OS/架构/libc、SHA256SUMS 校验、安装到 `~/.pi-web-x`（Windows 为 `%USERPROFILE%\.pi-web-x`）并注册用户级命令入口；幂等，同版本跳过。
