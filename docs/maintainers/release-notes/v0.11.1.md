# pi-web-x v0.11.1 发布说明

> 状态：**Released**（2026-09-10 发布）。本文是已发布版本的冻结归档；发布流程见 [`../release.md`](../release.md)。

## 概要

v0.11.1 是一个修复版本，集中解决 v0.11.0 发布后暴露的三类用户可感知缺陷：

1. **订阅登录无法完成授权**：点开订阅登录后授权页刚打开几秒，界面就报 "Connection lost"，授权流程作废。
2. **会话静默期事件流断开 / 文件 watch 静默断开**：同类空闲超时问题的另外两个入口。
3. **侧边栏会话列表「加载中...」常驻**：列表数据正常但加载态永不消失。

三者根因相互独立，但前两条同源——`Bun.serve` 默认 `idleTimeout` 为 10 秒，空闲 SSE 连接会被服务端强制断开，而相应 SSE 流没有（或间隔过长的）心跳。

## 修复

### 订阅登录空闲超时断开（用户可感知：授权页停留任意时长都能完成授权）

- **改动前**：前端通过 `EventSource` 连接 `/api/auth/login/<provider>` 等待 OAuth 流程事件；用户跳转授权页面期间该 SSE 流完全静默（下一个事件要等授权回调才有）。`Bun.serve` 默认 `idleTimeout` 10 秒一到即强制断开连接，前端 `onerror` 触发显示 "Connection lost" 并主动关闭重连，登录流程作废——表现为"刚打开授权页面过几秒就报错，没法授权"。另有一个隐藏缺陷：客户端断开后服务端 `finally` 中的 `controller.close()` 可能对已取消的流再次 close 抛出未处理异常。
- **改动后**：auth 登录 SSE 流新增 5 秒心跳（SSE 注释帧 `:\n\n`，EventSource 协议层自动忽略，仅用于让连接不再"空闲"）；所有写入带关闭守卫，`finally` 统一走 `closeStream()`，重复 close 不再抛异常。
- **入口**：设置 → 模型 → 订阅登录（`GET /api/auth/login/<provider>` SSE 流，语义不变）。

### 会话事件流与文件 watch 流接入同一心跳（用户可感知：静默期不再掉线）

- **改动前**：agent 事件流（`/api/agent/<id>/events`）原有心跳间隔 30 秒——大于 10 秒空闲超时，会话静默（模型长时间思考、等待用户确认工具调用等）超过 10 秒时连接仍会被断开；文件 watch 流（`/api/files/...?type=watch`）完全没有心跳，文件 10 秒内无变更即断开，客户端失去变更通知。
- **改动后**：两处统一为 5 秒心跳（与 auth 流同一策略），并在 watcher error / catch / cancel 路径清理定时器，避免流关闭后定时器泄漏。
- **入口**：聊天窗口事件流、文件查看器的实时变更刷新。

### 侧边栏「加载中...」常驻（用户可感知：加载态如实反映加载状态）

- **改动前**：初始 `loadSessions(showLoading=true)` 在飞行中被 running 轮询或后台刷新的 `loadSessions(false, true)` 抢占 `sessionLoadIdRef`，`finally` 中 loadId 失配导致 `setLoading(false)` 被跳过，加载态永久卡住（列表数据正常，但「加载中...」一直显示）。
- **改动后**：改用并发计数器管理加载态——每个 showLoading 请求计数 +1/-1，仅当所有 showLoading 请求结束后才关闭加载态；"只接受最后一次结果"的去重语义不变。
- **入口**：侧边栏会话列表。

## 变更与加固

- 订阅登录打开授权页前校验外部链接协议：仅允许 `http:`/`https:`，拒绝 `javascript:` 等危险协议注入；SSE 登录帧的 JSON 解析增加容错，畸形帧直接忽略，不再中断登录流程。
- `bun test` 在测试发现阶段排除 `tests/e2e/`（bunfig.toml `pathIgnorePatterns`）：该目录为 Playwright 测试，由 `bun run test:e2e` 执行，此前裸 `bun test` 误扫会报 "Playwright Test did not expect test() to be called here"。

## 兼容与安全

- `/api/*` 路径、方法、状态码、JSON 字段与 SSE 事件语义不变；心跳为 SSE 注释帧，客户端无感。
- 产品命名空间保持断裂：`pi-web-x` 不读取、迁移或兼容旧 `pi-web:*` 浏览器标识。
- 默认仅监听 loopback。LAN 或反向代理部署必须使用 HTTPS，并使用浏览器访问认证或 `PI_WEB_X_PASSWORD`，或置于可信 VPN 后。
- Host/Origin 校验及 Host Runtime Environment 与 Project Command Environment 的隔离保持不变。
- 无依赖变更，无依赖保留/替代变更，`docs/maintainers/runtime-substitution-matrix.md` 无需同步更新。
- 上游基线与 v0.11.0 一致（pi SDK `0.85.1`，构建环境 Bun `1.4.0`）。
