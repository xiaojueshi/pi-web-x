# pi-web-x v0.9.2 发布说明

> 状态：**Released**。本文是已发布版本的冻结归档；发布流程见 [`../release.md`](../release.md)。

## 概要

v0.9.2 是 v0.9.1 的 CI 热修复版本，修正了 systemd 服务迁移测试在 Windows Runner 上混用 POSIX 与 Windows 路径分隔符的问题。

## 修复

- systemd 服务迁移测试的旧 env 路径改为通过 `node:path.join()` 构造，与被测实现保持相同的平台路径语义；Windows CI 恢复通过。

完整变更见 [`../../../CHANGELOG.md`](../../../CHANGELOG.md)。

## 兼容与安全

- 不改变运行时服务逻辑、API 契约或 Pi 依赖版本。
- 产品命名空间保持断裂：`pi-web-x` 不读取、迁移或兼容旧 `pi-web:*` 浏览器标识；Pi 通用数据仍位于 `~/.pi/agent`。
- 默认仅监听 loopback。LAN 或反向代理部署必须使用 HTTPS，并使用浏览器访问认证或 `PI_WEB_X_PASSWORD`，或置于可信 VPN 后。
- Host/Origin 校验及 Host Runtime Environment 与 Project Command Environment 的隔离保持不变。

## 构建与制品

- 构建环境：Bun `1.4.0`。
- 制品目标：darwin x64/arm64、linux glibc x64/arm64、linux musl x64/arm64、windows x64/arm64。
- Draft Release 必须包含八个 `pi-web-x-*` 二进制、`pi-web-x-assets-0.9.2.tar.gz` 及 `SHA256SUMS`。
- GitHub Actions 在推送 `v0.9.2` 后自动创建 Draft Release；确认制品与校验和后发布。
